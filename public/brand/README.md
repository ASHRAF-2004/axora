# Axora pilot brand assets

This folder contains the visual identity prepared for the Axora internal
procurement and operations pilot.

## Assets

- `axora-mark.svg` is the compact application mark used in the interface and
  browser metadata.
- `axora-logo.svg` is the horizontal Axora Operations lockup for documents,
  guides, and larger layouts.
- `axora-icon-32.png` is the small browser fallback icon.
- `axora-apple-180.png` is the Apple touch icon generated from the mark.
- `lucide-boxes-source.svg` is the original Lucide `Boxes` source retained for
  provenance. Create derivatives from it; do not overwrite the source copy.

## Colour palette

- Primary navy: `#102A43`
- Action blue: `#2563EB`
- Operations teal: `#0F9D8A`
- Dark text: `#0F172A`
- Light background: `#F8FAFC`
- White: `#FFFFFF`

Use the blue mark on light or dark neutral backgrounds. Keep its proportions
unchanged and leave clear space around it. Use the horizontal lockup where the
word `Axora` is not already visible nearby.
