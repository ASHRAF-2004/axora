# Axora manuals

This directory builds the four published procurement manuals without using a
database, browser session, authentication cookie, or production record.

## Build and verify

```bash
npm run manuals:verify
```

The command:

1. builds the exact four PDFs into `output/pdf/`;
2. publishes the same bytes into `public/manuals/`;
3. performs a second deterministic build;
4. proves that both SHA-256 hashes match;
5. validates page counts, embedded Noto fonts, required guidance, forbidden
   wording, unresolved placeholders, clipping and the publication allowlist;
6. renders every page to PNG with PyMuPDF under
   `output/playwright/manuals/rendered/` for visual inspection.

The publication allowlist is:

- `axora-company-user-manual-en.pdf`
- `axora-company-user-manual-ar.pdf`
- `axora-owner-admin-manual-en.pdf`
- `axora-owner-admin-manual-ar.pdf`

The generator uses the approved raster logo derivative from `public/brand/`.
Its workflow diagrams are deterministic illustrations generated by trusted
manual code. They are not application screenshots and contain no production or
sample account data.

The prior database-backed screenshot seed was removed. Manual generation must
remain isolated from all production databases and sessions.
